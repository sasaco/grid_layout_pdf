# GridLayoutPdf — Design

## 背景・目的 (Background & Purpose)

Python の自作 PDF 計算書ライブラリを設計する。A4.pdf の GridLayout に従って文字配置を調整し、計算書の書式と計算式の等号位置を統一する。

2026-10-19 方眼Excel出力の新規依頼：WebPierで使う本ライブラリに、PDFの代わりに方眼Excel（.xlsx）を出力するモードを作る。grill-with-docs で FR-021〜025 を確定した。範囲はライブラリのみで、WebPier は本仕様を意識した書き方で作り直す前提（WebPier 側の作業は WebPier リポジトリで別に行う）。文字サイズ0.5pt刻み・罫線の種類・書体名指定はPDFを含むライブラリ全体の変更で、片持ち梁の再現 fixture の期待値も直す。実装は計画の作成とユーザー承認の後に行う。
