# 方眼Excel の .xlsx は標準ライブラリで書き出す

方眼Excel では、分数線と図を Excel の図形（線・折れ線・矢じり・角丸四角・菱形・円・テキストボックス・グループ）で描く。しかし openpyxl は図形を書けず、XlsxWriter が書ける図形はテキストボックスだけである。どちらを使っても図形の DrawingML は自前で書くことになるので、`.xlsx` 全体を `zipfile` と XML で書き出す部分をライブラリの中に持つことにした。openpyxl の出力に図形の XML を後から差し込む案は、openpyxl の内部の作りに頼るため、版が上がると壊れやすいので採らなかった。ZIP の日時と要素の順番を固定し、同じ原稿から同じバイト列を出す（PDF の `invariant=True` と同じ扱い）。製品の依存は増やさない。

## Consequences

- SpreadsheetML・DrawingML を書く部分（推定 1,500 行程度）はこのリポジトリで保守する。
- 正しさは、openpyxl（開発用の依存）での読み戻しと図形の XML の検査、および Excel がある環境での COM による検査（修復なしで開くこと、Excel から書き出した PDF との比較）で確かめる。
